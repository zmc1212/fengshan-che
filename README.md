# 风扇车 FENGSHAN-CHE — 机构复刻 No.08

《天工开物·乃粒》扇车:手摇 6 叶扇轮在圆箱内鼓风,谷物自漏斗经活门落下
穿风道被吹——糠秕轻被吹入远口,谷粒重落近口,风选分级。偏移-粒重关系
可验算,糠/谷落点分级载入断言。B 键查看剖视图。

## 机构与验算

```
尺寸(演示值):
  扇叶轮  6 叶,R 0.30,绕 X 轴,手摇曲柄
  风道箱  圆腔 + 渐扩风道 + 远/近两出口
  谷斗    活门率 ∝ 开度(26 粒/s)

分级验算(载入期断言):
  下落时间 t = √(2×0.95/9.8) = 0.44 s
  糠偏移 = ½×3.2×0.44² = 0.31 m → 远口
  谷偏移 = ½×0.9×0.44² = 0.09 m → 近口
  糠谷比 ≈ 34%(生成比);风速减半分级不升反降(线性断言)
```
